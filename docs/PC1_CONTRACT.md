# PC-1：管理端工程与身份基础

日期：2026-09-19。工程位置经用户选择为当前仓库 `admin/`，独立构建与发布。
设计沿用 [温润经营台](design/admin/README.md)，组件库为 antdv-next；本阶段不建立 Flutter 工程。

## 交付范围

- 官方 create-vue 初始化，Vue 3 + TypeScript strict + Vite + pnpm，直接依赖及锁文件固定版本。
- 应用主题、中文语言、响应式侧栏与账号菜单；角色过滤及路由守卫。
- 真实员工登录、GET /me 恢复、密码修改、到期清理、退出及异常恢复。
- OpenAPI 类型生成、RFC 9457 错误、统一 Bearer、请求取消与旧会话响应隔离。
- 只读工作台／门店摘要用于验证布局和角色共用接口，不引入虚构订单或财务数据。
- Table、Form、DatePicker、Upload、Drawer 的开发环境兼容性验收页；生产构建排除。

订单履约、通知中心与 WebSocket、商品／顾客／员工管理、资金与报表页面属于 PC-2—PC-5。
当前导航可见但未交付的入口禁用，直接访问对应路由显示“暂未开放”；STAFF 仍不能通过直达 URL 进入管理员区域。
工作台没有设计稿中的待接订单操作表及通知连接状态，不宣称这些后续能力已实现。

## 目录与依赖

app 负责装配及路由，modules 按 auth/workspace 分包，shared 提供框架通用的 HTTP、UI、时间能力。
跨模块使用 index.ts；页面暴露异步加载函数。边界检查阻止 shared 依赖业务、业务依赖 app 或外部访问业务内部目录。
自编代码使用中文职责和关键逻辑注释，生成类型保留明确的自动生成说明。

Node 24.21.0 为最新 LTS 分支版本；pnpm 12.4.2。具体锁定版本与 TypeScript 5.9.3 的兼容性取舍见
[管理端说明](../admin/README.md)。不将“最新”理解为无条件采用预发布版本或越过 peer 约束。

## 会话与请求边界

登录成功取得 hme_ Bearer 后仍读取当前身份；sessionStorage 只保存令牌与 expiresAt，不保存可被信任的角色。
刷新恢复必须重新 GET /me。401/403 恢复失败撤销候选会话；网络或503暂时失败显示重试界面，不能进入受保护页面。
有效会话按到期时刻设置清理计时；服务端数据库权限始终为准。

更换会话先取消旧请求并增加代数，再清理查询缓存。即使底层忽略取消，旧代数的200/401响应也不会污染新用户。
公开登录与门店请求不附加旧 Bearer；API只能访问当前来源 `/api/v1/`，不向外部地址发送令牌。
请求采用 credentials=omit 和 no-store，15秒超时；读写默认不自动重试。角色被拒返回403，不错误地登出有效用户。

改密只发 currentPassword/newPassword；成功清理会话并要求重新登录。表单离开有未保存提示，密码不持久化。
退出尝试服务端撤销，失败也完成本地清理，并明确服务端撤销尚未确认。安全跳转只允许本站相对页面路径。
