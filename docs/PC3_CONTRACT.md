# PC-3：订单作业与工作台闭环

日期：2026-09-20。沿用 Vue 3、TypeScript、antdv-next、pnpm 和既有浅鼠尾草／墨绿设计。

## 交付范围

| 页面／入口 | 能力 | 权限 |
| --- | --- | --- |
| /orders | 真实订单状态、完整 UUID、顾客 UUID、下单收货手机号及创建日期组合筛选；服务端分页 | ADMIN / STAFF |
| /orders/:id | 可直接刷新访问的订单详情；宽桌面并排，窄桌面抽屉 | ADMIN / STAFF |
| 订单详情操作 | 接单、拒单并退款、取消并退款、开始配送、确认完成 | ADMIN / STAFF，服务端再次检查状态和版本 |
| 工作台 | 全店当前待办可跳转；真实待接订单前5条；今日摘要及门店目录状态 | ADMIN / STAFF |
| 顾客详情 | 跳转该顾客的订单列表 | ADMIN |

通知中心、WebSocket、资金流水及报表页面留在 PC-4/PC-5。订单详情仅展示已有 paymentId/refundId 供复制，
不链接到尚未交付的资金页面。没有新增创建订单、模拟支付、任意退款金额、打印、派单或自由文本取消原因能力。

## 查询、列表与导航

- 使用 `/api/v1/management/orders`，条件按 AND 在数据库执行；page 从0、size默认20、可选50。
- 默认不限制创建日期，工作台当前待办跨所有日期，不能擅自截为今天。
- 状态页签为全部、待接单、待配送、配送中，全部状态选择器覆盖八种状态，不伪造每个筛选下的全量计数。
- UUID 要求完整值；界面可缩略为前8位／后4位，复制及请求仍使用完整 UUID。
- 手机号精确匹配成交时收货快照，列表不展示它没有返回的姓名、电话、商品和支付信息。
- 日期按 Asia/Shanghai 起日零点至结束日期次日零点转换为 UTC 左闭右开区间；不是报表日期协议。
- 输入非法 UUID、日期范围、手机号或路由分页时显示错误，禁止悄悄退化为无条件查询。
- URL 仅保存状态、UUID、日期和分页；手机号只保存在当前页面内存，不写入路由、查询键或持久化缓存。
- 详情打开／关闭保留列表筛选与页码，浏览器刷新可重新读取详情；通过路由后退恢复非敏感筛选。
- 不增加前端全量排序、批量操作或逐行查详情请求。表格保持后端排序与 totalElements。

## 详情与快照

显示订单编号、状态、真实生命周期时间、商品名称／规格／单价／数量／小计、套餐组成、总金额、收货快照、
催单次数／最近时间、固定取消原因和独立退款状态。商品和地址完全来自订单快照，不再查实时目录或地址簿。
付款前金额叫订单金额，有 paidAt 后显示实付金额；不自行拆出运费、优惠或包装费。
手机号默认掩码，主动显示后仅在当前详情可见；切换订单或关闭详情后恢复掩码。
时间线只显示服务端有值的时刻，不制造退款完成时间或预计送达。

## 操作表

| 状态 | 中文 | 合法操作 |
| --- | --- | --- |
| UNPAID | 待付款 | 只读，商家不能取消未付款订单 |
| PAID | 待接单 | 接单、拒单并退款、取消并退款 |
| ACCEPTED | 待配送 | 开始配送、取消并退款 |
| DELIVERING | 配送中 | 确认完成 |
| COMPLETED | 已完成 | 只读 |
| CANCELLING | 取消处理中 | 读取进度 |
| REFUNDING | 退款处理中 | 读取进度 |
| CANCELLED | 已取消 | 只读；独立展示真实退款状态 |

未知状态失败关闭，不暴露写按钮。退款 NONE/PENDING/SUCCEEDED 分别显示无需退款／退款处理中／已退款；
取消后的迟到付款可能仍需退款，不能因为订单 CANCELLED 就停止检查 PENDING 退款。

每次操作弹出含完整订单编号与影响的确认，冻结当时的 version。确认及提交期间停止详情轮询，禁止切换订单、
重复提交或对该订单执行第二个写命令。只发送 `{version}`，不会预设最终状态。
拒单／取消返回 REFUNDING 或 CANCELLING 时显示“已提交，等待服务端确认”；只有真实终态才展示完成。
成功后保留更新后的详情，即使订单已离开当前筛选，也允许员工确认结果；刷新订单列表及工作台缓存。

## 并发、故障与刷新

- 详情每次读取都带请求取消及代数，切换／卸载后旧结果不能覆盖新订单；沿用统一员工会话代数保护。
- 确认后若路由或会话已改变，不发送原命令；服务端仍通过当前身份、资源版本及行锁决定能否执行。
- 409或响应丢失保留原详情并阻止再提交；显式重新读取成功后才解除保护并重新生成状态动作。
- 读取失败保留已知内容并禁用写操作；403/404清除失效详情。错误使用统一 Problem／traceId 展示。
- 页面可见时每15秒核对列表、工作台及活动订单详情；请求未完成不重叠，隐藏页面暂停，重新可见时刷新。
- 完成／取消终态默认停止详情轮询，但退款仍PENDING时继续核对。确认／写入／冲突未重读期间不自动刷新详情。
- 查询层更新不覆盖正在填写但尚未应用的筛选。若投影故障，工作台提供直接进入订单中心的恢复入口。
- 工作台待办统计来自投影，列表来自权威订单；短暂差异如实保留，不篡改订单或伪造统计同步。
